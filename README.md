# 🏆 Bench2Dex Leaderboard

Official policy rankings and task-level results for Bench2Dex.

[🌐 Leaderboard](https://bench2dex.github.io/Bench2Dex-Leaderboard/) · [🏠 Project](https://bench2dex.github.io/) · [💻 Code](https://github.com/Bench2Dex/Bench2Dex) · [🧪 Evaluation logs](https://huggingface.co/datasets/Bench2Dex/Leaderboard)

## 🤝 Submit your policy results

Evaluate your policy on Bench2Dex and submit its results to this leaderboard via PR.

### 1. Submit metadata and scores to GitHub

Add your policy under:

```text
leaderboard/<policy_id>/
├── README.md
├── leaderboard_<policy_id>.json
└── logo.svg / logo.png / logo.webp
```

- **README:** reuse your policy's project introduction or link to its homepage.
- **JSON:** one policy object matching `policies[]` in [assets/data/leaderboard.json](assets/data/leaderboard.json), without an array wrapper. Keep the directory, filename, and `model.id` consistent; set `evaluation.isTemplate` to `false`.
- **Logo:** your contributing organization's logo; set `model.logoPath` to `leaderboard/<policy_id>/logo.ext`.

### 2. Submit original evaluation logs to Hugging Face

Submit the matching README/results JSON and `per_task_eval/` to the [HF Leaderboard repository](https://huggingface.co/datasets/Bench2Dex/Leaderboard#readme). Include the **original `per_episode.jsonl` and `summary.json` generated by Bench2Dex**, after sanitization. Preserve their native structure, fields, and units; no log conversion or extra template fields are required. **Evaluation logs belong in HF, not this GitHub repository.**

### 3. Open and link both PRs

Target **main** in both repositories and cross-link the PRs. Policy IDs, scores, coverage, and protocol must agree. After reviewing the logs, maintainers record the accepted HF commit in the GitHub results JSON's `evaluation.logs.revision` before publishing the entry.

## 📋 Result requirements

- **Ranking requires all three Overall metrics:** four-channel mean SR and LSCR, and pooled Eff., with complete results for all 26 tasks. Partial submissions remain visible with Score NR and no rank.
- **Score** = 0.45×SR + 0.45×LSCR + 10×Eff., on a 0–100 reference scale. SR/LSCR use percentages; Eff. is the raw, uncapped ratio. Higher is better. The leaderboard computes Score from the submitted metrics.

- At least **Full** results and logs are required for submission; **None · Equi. · Inv. · Full** are encouraged. Ranking requires the complete three-metric results described above.
- List all 26 tasks in the results JSON. Its SR/LSCR values use **0–100** percentages and Eff. is a ratio; missing values are `null` (NR). Full-only scores are not four-channel means. Keep native log units unchanged.
- Report actual episode counts, execution budgets, and deviations from the 50-episode/task/channel reference. Follow the [metric definitions](https://bench2dex.github.io/Bench2Dex-Leaderboard/#protocol-notes).

## 🔒 Privacy and permissions

Replace private absolute paths with relative paths or consistent anonymized identifiers. Redact credentials, personal/confidential information, internal URLs, and restricted content in files, media, links, and PR descriptions. Preserve log structure, metrics, episode counts, seeds, and protocol metadata. Confirm publication rights for results, logs, documentation, and the logo under applicable licenses and data-use terms.

Open weights and inference code are encouraged; policy integration PRs are welcome in [Bench2Dex](https://github.com/Bench2Dex/Bench2Dex).

The existing Bench2Dex Team reference entries are maintained in [leaderboard/](leaderboard/). [assets/data/leaderboard.json](assets/data/leaderboard.json) supplies the published leaderboard and project homepage.
